# Źródła grafik Umysłu z ciała (`aquila/icons/fleshmind/`)

Pliki przeniesione bez zmian rysunku z Bubberstation/Bubberstation (`modular_zubbers/icons/fleshmind/`, commit 88d7efe2,
Bubberstation/Bubberstation#4914, wcześniej Skyrat-SS13/Skyrat-tg#14023). Grafiki i dźwięki Fleshminda pochodzą z
eventu Hivemind z discordia-space/CEV-Eris (discordia-space/CEV-Eris#2894, autor Macleod962). Kod: `aquila/code/modules/events/hexmap/fleshmind/`.

| Plik | Co jest w środku |
|---|---|
| `fleshmind_machines.dmi` | rdzeń, struktury roju (wieżyczka, głowa, montownia, antena, psi-modulator, kula), nakładki zainfekowanych maszyn |
| `fleshmind_mobs.dmi` | moby roju (bez `mauler_monkey`, którego nie przenosimy) i nakładka `human_overlay` |
| `fleshmind_structures.dmi` | ściana i drzwi z przewodów, pocisk wieżyczki, przewody w wentylacji |
| `wireweed_floor.dmi` | przewody na podłodze (stany `wires-0`…`wires-255` jak bitmaska smoothingu tg), animacja rozrostu |
| `tyrant.dmi` | Mięsonapęd 34-C (64×64) |
| `fleshmind_clothing.dmi`, `fleshmind_clothing_onmob.dmi` | szata i kaptur kapłana przewodów |
| `fleshmind_objects.dmi`, `fleshmind_objects_onmob_l.dmi`, `fleshmind_objects_onmob_r.dmi` | laska kapłana przewodów |

# Goon-ported-assets

All files excluding this one you're reading right now have been most likely, taken from [goonstation's 2016 release](https://github.com/goonstation/goonstation-2016), unless stated otherwise.
It is very likely that there are modifications to be compatible or on par with our code, however. These changes are licensed under the same license as the other goon files.

## Files from the current goonstation repository

- `icons/obj/loudspeakers.dmi` - from [goonstation/goonstation](https://github.com/goonstation/goonstation) (`icons/obj/loudspeakers.dmi`), same CC BY-NC-SA 3.0 license. Used by the Aquila jukebox amp stack and the Syndicate speaker.
- `icons/obj/matsci.dmi` - states `plater0` and `plater1` from Monkestation/Monkestation2.0 (`goon/icons/matsci.dmi`), same CC BY-NC-SA 3.0 license. Used by the Aquila munitions forge electroplater.
- `icons/mob/genetics_powers.dmi` - 13 states from [goonstation/goonstation](https://github.com/goonstation/goonstation) (`icons/mob/genetics_powers.dmi`), same CC BY-NC-SA 3.0 license. `firebreath1` and `cryokinesis1` are brightened copies for the active state of aimed spells. Used as action buttons of genetic powers (`aquila/code/datums/mutations/goon_ikony.dm`).
